# OCR集成与效率优化方案

## 一、集成方案

### 1.1 架构设计

```
主抓取流程 (flight_scraper_12306.py)
    ↓
混合提取模式 (page_capture_ocr.py)
    ├─ OCR模式 (优先，适用于H5/WebView)
    └─ XML模式 (备用，适用于原生页面)
    ↓
解析器
    ├─ OCR解析器 (parser_ocr.py)
    └─ XML解析器 (parser.py)
    ↓
数据保存
```

### 1.2 已完成的集成

1. **创建了OCR抓取模块** (`page_capture_ocr.py`)
   - `smart_scroll_and_capture_ocr()`: 纯OCR模式
   - `smart_scroll_and_capture_hybrid()`: 混合模式（OCR优先，XML备用）

2. **创建了OCR解析器** (`parser_ocr.py`)
   - 从OCR文本中提取航班号、时间、价格等信息

3. **修改了主抓取流程** (`flight_scraper_12306.py`)
   - 优先使用OCR模式
   - 自动回退到XML模式

## 二、效率优化方案

### 2.1 当前性能分析

**测试结果对比：**
- XML提取：5个航班，约30秒
- OCR提取：28个航班，约60秒（20次滚动）

**性能瓶颈：**
1. OCR识别速度：每次截图OCR识别需要2-3秒
2. 滚动等待时间：每次滚动后等待2.5秒
3. 截图保存：保存截图需要额外时间

### 2.2 优化方案

#### 方案1：智能滚动检测（已实现）
- **原理**：连续3次无新内容时提前停止
- **效果**：减少不必要的滚动和OCR识别
- **预期提升**：20-30%

#### 方案2：减少等待时间
- **当前**：每次滚动后等待2.5秒
- **优化**：根据页面加载速度动态调整（1.5-2秒）
- **预期提升**：15-20%

#### 方案3：批量OCR处理
- **原理**：收集多张截图后批量OCR识别
- **实现**：每3-5次滚动后批量处理
- **预期提升**：10-15%
- **风险**：可能错过中间的新内容

#### 方案4：选择性截图保存
- **当前**：保存所有截图（用于调试）
- **优化**：只保存前10张或出错时的截图
- **预期提升**：5-10%

#### 方案5：并行OCR处理（高级）
- **原理**：使用多线程/多进程并行OCR识别
- **实现**：需要线程池或进程池
- **预期提升**：30-50%
- **复杂度**：高，需要处理线程安全

#### 方案6：OCR区域优化
- **原理**：只对包含航班信息的区域进行OCR
- **实现**：识别页面布局，只OCR列表区域
- **预期提升**：20-30%
- **复杂度**：中，需要页面布局分析

#### 方案7：缓存机制
- **原理**：缓存已识别的航班，避免重复处理
- **实现**：使用set去重（已实现）
- **预期提升**：已优化

### 2.3 推荐优化组合

**短期优化（易实现）：**
1. ✅ 智能滚动检测（已实现）
2. 减少等待时间到1.5-2秒
3. 选择性截图保存（只保存前10张）

**中期优化（需要开发）：**
4. OCR区域优化（只识别列表区域）
5. 动态等待时间调整

**长期优化（高级功能）：**
6. 并行OCR处理
7. 机器学习优化OCR识别准确率

### 2.4 预期性能提升

| 优化方案 | 实现难度 | 预期提升 | 优先级 |
|---------|---------|---------|--------|
| 智能滚动检测 | 低 | 20-30% | ✅ 已实现 |
| 减少等待时间 | 低 | 15-20% | 高 |
| 选择性截图 | 低 | 5-10% | 中 |
| OCR区域优化 | 中 | 20-30% | 高 |
| 动态等待时间 | 中 | 10-15% | 中 |
| 批量OCR处理 | 中 | 10-15% | 低 |
| 并行OCR处理 | 高 | 30-50% | 低 |

**总体预期：** 实施短期优化后，性能可提升 **40-60%**

## 三、使用指南

### 3.1 启用OCR模式

主抓取流程已自动启用OCR模式，无需额外配置。

### 3.2 手动选择模式

```python
from page_capture_ocr import smart_scroll_and_capture_ocr, smart_scroll_and_capture_hybrid

# 纯OCR模式
flights, screenshots = smart_scroll_and_capture_ocr(driver, output_dir, use_ocr=True)

# 混合模式（推荐）
flights, method = smart_scroll_and_capture_hybrid(driver, output_dir, prefer_ocr=True)
```

### 3.3 性能调优参数

```python
# 调整滚动参数
flights, _ = smart_scroll_and_capture_ocr(
    driver, 
    output_dir,
    use_ocr=True,
    max_scrolls=30,      # 最大滚动次数
    min_scrolls=3        # 最小滚动次数
)
```
