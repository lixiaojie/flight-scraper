# 增强版步骤指南

## 🚀 最新改进

### 1. 步骤1: 应用重启
**功能**: 确保12306应用从首页开始
**实现**: 
- 先终止应用 (`terminate_app`)
- 等待1秒
- 重新启动应用 (`activate_app`)

### 2. 步骤5: 页面刷新机制
**功能**: 当查询按钮未找到时自动刷新页面
**实现**:
- 最多重试3次
- 主要刷新方法: `driver.refresh()`
- 备用刷新方法: `driver.back()` + `driver.forward()`

### 3. 等待时间优化
**改进**: 所有等待时间从5秒缩短为2秒
**影响**:
- 提高脚本执行速度
- 减少不必要的等待时间
- 保持足够的页面加载时间

## 🔍 故障排除

### 常见问题

#### 1. 应用重启失败
**症状**: `terminate_app` 或 `activate_app` 失败
**解决方案**:
- 检查应用包名是否正确
- 确认应用已安装
- 检查设备连接状态

#### 2. 页面刷新无效
**症状**: 刷新后仍找不到查询按钮
**解决方案**:
- 检查页面是否支持刷新
- 尝试不同的刷新方法
- 增加等待时间

#### 3. 等待时间过短
**症状**: 页面加载不完整
**解决方案**:
- 增加 `wait_step` 参数
- 检查网络连接
- 调整重试间隔
