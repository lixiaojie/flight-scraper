# 城市选择功能测试模块

## 📋 功能说明

这是一个独立的单元测试模块，用于测试12306空铁联运首页的城市选择功能。

### 测试内容

1. **识别城市位置**: 在空铁联运首页识别出发城市和到达城市的位置
2. **进入选择页面**: 点击城市元素，进入城市选择页面
3. **搜索城市**: 在顶部搜索框输入城市名称的首字母（拼音）
4. **选择城市**: 在搜索结果中选择目标城市
5. **返回上一页**: 选择完成后返回空铁联运首页
6. **保持页面**: 测试完成后，设备停留在空铁联运首页，方便手动检查结果

## 🚀 使用方法

### 方法1: 直接运行Python脚本

```bash
cd scripts
python3 test_city_selection.py
```

### 方法2: 使用运行脚本

```bash
cd scripts
./run_city_selection_test.sh
```

### 方法3: 自定义测试城市

```bash
export TEST_FROM_CITY="北京"
export TEST_TO_CITY="上海"
python3 test_city_selection.py
```

### 方法4: 在Docker环境中运行

```bash
# 在Docker容器中运行
docker exec -it <container_name> python3 /app/scripts/test_city_selection.py
```

## ⚙️ 环境变量配置

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `TEST_FROM_CITY` | 测试的出发城市 | `北京` |
| `TEST_TO_CITY` | 测试的到达城市 | `上海` |
| `SCRAPER_DEVICE_UDID` | 设备UDID | `emulator-5554` |
| `APPIUM_SERVER_URL` | Appium服务器地址 | `http://localhost:4723` |
| `SCRAPER_CONFIG_PATH` | 配置文件路径 | 自动检测 |

## 📝 测试流程

1. **连接设备**: 自动连接到指定的模拟设备或物理设备
2. **启动应用**: 启动12306应用
3. **导航到空铁联运首页**: 
   - 检查主页面
   - 点击空铁联运按钮
   - 验证进入空铁联运首页
4. **测试出发城市选择**:
   - 查找并点击出发城市元素
   - 进入城市选择页面
   - 在搜索框输入城市首字母
   - 从搜索结果中选择城市
   - 返回上一页
5. **测试到达城市选择**: 重复上述步骤
6. **保持页面**: 测试完成后，设备停留在当前页面，等待用户检查

## 🐛 故障排除

### 问题1: 无法找到城市元素

**可能原因**:
- 页面结构发生变化
- 元素定位方式需要更新

**解决方法**:
- 使用Appium Inspector检查页面结构
- 更新 `find_city_element()` 函数中的选择器

### 问题2: 无法找到搜索框

**可能原因**:
- 城市选择页面的搜索框ID或类名发生变化

**解决方法**:
- 检查页面源码，更新 `find_search_box()` 函数

### 问题3: 无法选择城市

**可能原因**:
- 搜索结果中城市名称不完全匹配
- 需要滚动才能看到目标城市

**解决方法**:
- 脚本已包含自动滚动功能
- 可以调整 `select_city_from_results()` 函数中的匹配逻辑

### 问题4: 设备连接失败

**解决方法**:
- 确保设备已连接并可用: `adb devices`
- 确保Appium服务器正在运行
- 检查环境变量配置是否正确
